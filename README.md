## 🛠️ Getting Started

### Clone Repository

```bash
git clone https://github.com/shubhamdsk/shubham-portfolio.git
cd shubham-portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
ng serve
```

Navigate to:

```text
http://localhost:4200
```

---

## 📦 Build Project

```bash
ng build
```

Production build files will be generated inside:

```text
dist/
```
